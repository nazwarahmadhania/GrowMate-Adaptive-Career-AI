🏎 Race Strategy — Personalized Learning Roadmap
LAP 1 SQL Lanjutan & Query Optimization 6 jamHIGH
🏁 Kuasai teknik query lanjutan untuk menarik dan mengolah data dari database layaknya seorang Data Analyst profesional.
  • Review dasar SQL — SELECT, WHERE, GROUP BY, ORDER BY
  • Pelajari & praktikkan semua tipe JOIN (Inner, Left, Right, Full Outer)
  • Pelajari Aggregations lanjutan & klausa HAVING
  • Pelajari Window Functions: ROW_NUMBER(), RANK(), SUM() OVER()
  • Kerjakan minimal 5 soal latihan SQL di LeetCode / HackerRank
📚 Mode Analytics SQL Tutorial  ·  HackerRank SQL  ·  SQLZoo
LAP 2 Data Visualization & BI Dashboard 6 jamHIGH
🏁 Ubah data mentah menjadi dashboard visual interaktif yang bisa berbicara kepada stakeholder bisnis.
  • Pahami prinsip desain visual & pemilihan jenis chart yang tepat
  • Koneksikan dataset CSV ke Tableau Public atau Power BI
  • Buat calculated fields / measures sederhana
  • Susun layout dashboard interaktif (filter & parameter)
  • Rangkum minimal 3 insight bisnis dari dashboard yang dibuat
📚 Tableau Free Training  ·  Microsoft Learn Power BI
LAP 3 EDA dengan Python (Pandas, NumPy, Seaborn) 6 jamHIGH
🏁 Gunakan Python untuk data cleaning dan Exploratory Data Analysis — skill inti yang mengisi 70% pekerjaan harian Data Analyst.
  • Review Python dasar yang sudah dimiliki (list, dict, fungsi)
  • Pelajari Pandas: read_csv, groupby, merge, handling missing values
  • Pelajari NumPy: array operations & statistik dasar (mean, median, std)
  • Buat visualisasi dengan Matplotlib & Seaborn (histogram, boxplot, heatmap)
  • Tulis EDA report singkat berisi statistical summary & key insight
📚 Kaggle Learn — Pandas & Python  ·  Real Python Data Analysis
🏆 LAP 4 Mini Project Portofolio + Interview Prep 6 jamFINISH LINE
🏁 Gabungkan semua skill ke dalam 1 project end-to-end siap CV & GitHub, lalu latih komunikasi teknis untuk memenangkan interview!
  • Pilih dataset publik dari Kaggle / Google Dataset Search
  • Jalankan pipeline lengkap: cleaning → EDA → SQL query → visualisasi
  • Tulis README: business problem, proses analisis, insight & rekomendasi
  • Upload & rapikan dokumentasi project ke GitHub / portofolio pribadi
  • Latihan jelaskan project dengan teknik STAR method untuk interview
